# AI Curated Insights

RSS/Atom → краткий пересказ (OpenAI) → Telegram-черновики на проверку.

## Режим

- `PUBLISH_ENABLED=false` (по умолчанию): пайплайн только собирает и выводит превью в лог.
- `PUBLISH_ENABLED=true`: отправляет до `MAX_PER_RUN` новых черновиков в тестовый канал. Каждый черновик помечен «ЧЕРНОВИК на проверку» и содержит ссылку на источник.

## Настройка

1. Секреты репозитория: `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN` (токен бота-администратора канала).
2. Переменные репозитория: `TELEGRAM_CHAT_ID` (id тестового канала), `PUBLISH_ENABLED` (`true`, когда готовы к черновикам).
3. Источники: `config/sources.json`. X не используется (нет бесплатного API). Адреса со статусом `to_verify` проверяются первым запуском по логу `FEED_ERROR`.

## Проверки

- `npm test`: разбор фидов, экранирование HTML в черновиках, отказ публиковать без токена.
- Дедупликация: отправленные ссылки хранятся в `state/seen.json` и переносятся между запусками через кеш Actions.
